Architectural Reference & Key Decisions Walkthrough

System Overview

ReminderPilot is a personal deadline assistant web app designed to capture tasks, due dates, amounts, and categories from unstructured bills, appointment notices, and subscription renewals.

The app combines a Spring Boot REST backend (Java 21/25 with Google Gemini 3.8 Flash + local heuristic fallback) and a responsive React single-page frontend (Vite with zero-dependency browser localStorage persistence).

To Change This, Start Here

Backend Extraction Model or Prompt: Edit backend/src/main/resources/application.properties and prompt template in ExtractionService.java.
Categories & Badge Palette: Edit frontend/src/features/reminders/constants.js and pill CSS in frontend/src/styles/global.css.
Urgency Thresholds (Today / Overdue): Adjust date calculation helpers in frontend/src/utils/dateUtils.js → getUrgencyStatus().
Card Layout or UI Styles: Modify variables in frontend/src/styles/variables.css and components in frontend/src/components/.

A Practice to Reuse: Decoupling Identity from Provider Interpretation

The Problem: When using generative AI for data processing, different runs or fallback models can produce slightly different semantic summaries (e.g., "Pay broadband bill" vs "Airtel Xstream Fiber: Your monthly broadband bill...") for the exact same input notice.

The Reusable Solution: Calculate a deterministic fingerprint of the normalized raw input (sourceFingerprint) on ingestion. Use this fingerprint as the primary identity key for duplicate detection, while using the extracted semantic fields for display and secondary matching.

This guarantees exact deduplication consistency regardless of model drift, temperature variance, or offline fallback switches.
